# Embedded FlightGear model adaptations

The game embeds these meshes and textures. No model download, Blender installation
or external asset file is needed at run time. Editable corresponding sources are
included in `source/` with original material images and XML credits. AC3D and
XML inputs used by the converter are stored as lossless gzip files. `sources.json`
records SHA-256 hashes of the uncompressed upstream inputs.

Viper Run adaptations include axis/datum conversion, dimensional calibration,
flat shading, moving-part separation, game-compatible pylons, a single
680 x 260 mm Su-27 nose wheel replacing the common model's naval twin wheels,
cockpit closure, front-board and HUD reconstruction, pedal-tunnel and throttle
quadrant openings, and live instrument faces. Original cockpit programs are not run. Changes and references are
recorded in [HORNET-FLANKER-MODELS.md](../../docs/HORNET-FLANKER-MODELS.md).

## Rebuild without network access

Super Hornet/Growler sources, author permission and their separate hash manifest
are under `source/superhornet/` and `superhornet-sources.json`. Restore them with
the same unpack command below, then run `tools/import_superhornet.py` against
the restored `superhornet` directory. The two variant VRM/VRZ files and flat
skins are reconstructed offline. See
[HORNET-CANOPY-SUPER.md](../../docs/HORNET-CANOPY-SUPER.md) for the source package,
datum, E canopy reconstruction, weapon mounts, references and limitations.

Install Pillow from `tools/requirements-models.txt`, then from the repository root:

```sh
python tools/import_flightgear.py --unpack-source target/model-source-restored
python tools/import_flightgear.py --source-root target/model-source-restored
python -m unittest discover -s tools -p test_flightgear_import.py -v
cargo test
./build.sh
```

`*.vrm` contains named flat-shaded triangle meshes and lossless QOI cockpit images.
`*-skin.qoi` contains cleaned exterior images in a 48-colour palette.
Cockpit source panels use 64 colours. Small insignia and warning colours have
reserved palette entries; source image aspect and UVs remain unchanged. Images
up to 2048 pixels retain their resolution, and larger images scale uniformly.
Median filtering removes painted speckle, and QOI packages the styled pixels
losslessly. Functional instruments retain their live vector/canvas rendering.
`geometry.json` inventories parts, used object bounds and native texture dimensions.

To inspect the embedded exterior meshes in Linux Blender:

```sh
blender --background -t 4 --python tools/review_flightgear.py -- target/model-review/blender
```

This writes orthographic PNG views and editable `.blend` review scenes into the
ignored target directory. Captures of the running game, including moving surfaces
and stores, are generated by `tools/check_airframe_views.py`.
